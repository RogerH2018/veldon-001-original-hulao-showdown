# 实现决定

<!-- ASK mode: never -->

| ID | 问题 | 选择 | 类别 | 来源 |
| --- | --- | --- | --- | --- |
| A-001 | 初版模式和规则 | 两名原创角色，单人电脑战或双人同屏，55 秒一局，两胜获胜 | semantic | default |
| A-002 | 沿用的功能 | 双方键位和三个连招槽，数字方向随角色朝向，保留等待帧、改键、难度、暂停及键位界面 | interface | user |
| A-003 | 新战斗的指令语义 | A 轻击、B 进击、C 破防、D 脉冲。236A 冲刺、214B 后撤反击、236D 消耗能量发射脉冲。按键与宏走同一路径 | semantic | default |
| A-004 | 运行环境 | 中文界面、键盘和多点触控、设置保存在本地浏览器。独立静态仓库部署到 GitHub Pages | interface | default |
| A-005 | 代码和素材 | 浏览器原生模块，无运行依赖。角色原画由 ImageGen 生成，项目代码绘制场景并驱动动作和音效。发布时由项目所有者决定再使用条款 | interface | default |
| A-006 | 回合结算 | 超时以剩余生命分胜负。生命相同的回合不计胜局，每一局重置生命与能量 | semantic | sweep |
| A-007 | 对阵角色 | 默认 1P 是棱锚，默认对手是流梭。两方都可独立更换角色 | semantic | sweep |
| A-008 | 普通攻击输入 | 新按下时出招。同时按键按 D、C、B、A 顺序选一个。出招和受击期间的普通攻击输入不缓冲，特殊指令读取最近 26 帧的方向变化。专属技见 A-022 | semantic | sweep |
| A-009 | 防御 | 站在地面时后退或蹲下可防御，C 破防。成功防御无伤害，但有防御硬直、退距和能量收益 | semantic | sweep |
| A-010 | 能量 | 百人版初始 42，最高 100，攻防命中获取能量。236D 消耗 40，能量不足时是普通 D，启动后被打断无退还 | semantic | sweep |
| A-011 | 连续命中提示 | 统计间隔小于 54 帧的命中数，HUD 标成「连续命中」 | semantic | sweep |
| A-012 | 电脑难度 | 入门、标准、进阶每 29、17、10 帧决策，后两档可以预判防御。标准默认。百人版专属技见 A-021 | semantic | sweep |
| A-013 | 自定义宏 | 单玩家同时运行一个宏，按触发时朝向解释方向，与手动输入合并，受击即取消 | semantic | sweep |
| A-014 | 设置恢复 | 旧设置先补默认角色并识别自定义宏，再校验。失效的角色编号可单独恢复其默认角色。其他设置校验异常时使用默认项。保存失败时仍可使用当前会话，恢复默认按钮只影响绑定和连招 | interface | sweep |
| A-015 | 暂停与失焦 | 打开设置暂停模拟并清空输入，关闭后恢复此前暂停状态。切到隐藏标签时暂停对战，仍可见的失焦窗口仅释放输入 | interface | sweep |
| A-016 | 全屏与项目入口 | 支持 Fullscreen API 的浏览器可扩大当前游戏，项目链接指向已可访问的 Veldon Game GitHub 总目录 | interface | default |
| A-017 | 风格与选人 | 十支虚构队伍，每队十人。角色拥有各自的造型、数值和三套连招。两方都可选人，按队伍筛选和名称查找，并保存选择 | semantic | default |
| A-018 | 专属连招命中 | 三个角色槽分别为近身、追击和能量终结。首击仍可闪避、被打断或防住，首击命中后，在连招硬直内继续后续。连招进入恢复阶段后才能再用 | semantic | default |
| A-019 | 键位兼容 | 默认 L/O/P 与 3/6/9 运行专属连招，已有自定义宏与改键保留。选人面板和实战按钮提供相应角色的完整连招列表 | interface | default |
| A-020 | 资源和发行 | 原创角色立绘使用独立资产；同一资产用于选人和战斗，运行时配架势动画、轨迹、击中闪光和合成声效。沿用游戏现有公开仓库与试玩地址 | interface | default |
| A-021 | CPU 专属技 | 标准和进阶档会按距离和能量使用所选角色的专属连招，入门仍以移动和普通招式为主 | semantic | default |
| A-022 | 专属技缓冲 | 普通招式或专属技的最后 12 帧接受一个专属技快捷输入，新输入可覆盖上一项。启动前受击或暂停会取消缓冲 | semantic | sweep |
| A-023 | 触控宏 | 触控始终提供三个专属招式按钮，并为启用的自定义宏显示独立快捷按钮 | interface | sweep |
