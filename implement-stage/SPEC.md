# 弧港对决

Veldon 第 001 款自制网页格斗游戏。单人打电脑或本地双人，沿用按键布局、改键、连招方向和等待帧。原创角色、场景、声效及战斗引擎随浏览器版发布。输出为独立 Git 仓库及静态试玩页。运行 `npm test` 并在浏览器验证完整对战。新仓库在 F0 前没有提交。按键解析参考私有工作副本提交 `89e044ba8a26e78535039eca3e1f1b04b1b61f07`。

## 百人版本

基于 `77d10277c821c54ae6d1a2fe5bc2a7f96ee31232`。重做原创角色美术，单人和双人均能选 100 名角色，每名有三套命中判定、移动和特效。验收遍历 300 套连招，验证选人及真实按键，再通过现有 GitHub Pages 发布。
