# 弧港对决 · Arc Harbor

Veldon Game 第 001 款自制游戏。十支队伍的 100 名原创格斗家在夜潮货运码头交手，每人都有三套专属连招。

[网页试玩](https://rogerh2018.github.io/veldon-001-original-arc-harbor/) · [Veldon Game 项目](https://github.com/RogerH2018/Veldon-Game)

单人可挑战三个难度的电脑，同屏双人共用键盘或触屏。两方都能自由选人，可以按队伍筛选或搜索角色。每局 55 秒，两胜赢得整场。

| 操作 | 1P 默认 | 2P 默认 |
| --- | --- | --- |
| 移动 / 跳跃 / 蹲防 | W A S D | 方向键 |
| 轻击 / 进击 / 破防 / 脉冲 | J K U I | 1 2 4 5 |
| 近身连击 / 追击 / 能量终结 | L O P | 3 6 9 |
| 开始 / 暂停 | Enter / Esc | |

后退和下蹲可防御，C 破防。专属连招的首击命中后自动接续，每一段都独立扣血。近身连击需要靠近，追击会向对手移动，终结技按角色消耗能量。选人画面可查每套招式的名称、段数和消耗。实战时用默认快捷键，或点击键位区的招式按钮。

面向对手输入 **236A** 冲刺、**214B** 后撤反击、**236D** 消耗 40 能量发射脉冲。数字方向用小键盘记法，6 为前，4 为后。打开「连招 / 按键设置」可改键，切换到自定义宏还能编辑按键、等待帧和间隔。

## 本地运行

使用 Node.js 22 或更新版本。

~~~sh
npm run dev
npm test
~~~

打开终端显示的地址。游戏由浏览器原生模块运行，无运行时依赖。GitHub Pages 从 main 根目录提供静态文件。

## 代码和素材

键位与连招解析沿用作者自己的浏览器格斗项目。100 名原创角色的立绘来自 [本项目的图集生成提示词](assets/roster/PROMPTS.md)。码头、战斗动画和特效由 Canvas 绘制，声效由 Web Audio 合成。引擎测试覆盖了全部 300 套专属连招的两个对战方向。
