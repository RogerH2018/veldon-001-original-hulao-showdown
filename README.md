# 弧港对决 · Arc Harbor

Veldon Game 第 001 款自制游戏。夜潮涌入货运码头，重装的棱锚和轻装的流梭展开对决。

[网页试玩](https://rogerh2018.github.io/veldon-001-original-arc-harbor/) · [Veldon Game 项目](https://github.com/RogerH2018/Veldon-Game)

单人可挑战三个难度的电脑，同屏双人共用键盘或触屏。每局 55 秒，两胜赢得整场。

| 操作 | 1P 默认 | 2P 默认 |
| --- | --- | --- |
| 移动 / 跳跃 / 蹲防 | W A S D | 方向键 |
| 轻击 / 进击 / 破防 / 脉冲 | J K U I | 1 2 4 5 |
| 三个连招槽 | L O P | 3 6 9 |
| 开始 / 暂停 | Enter / Esc | |

后退和下蹲可防御，C 破防。面向对手输入 **236A** 冲刺、**214B** 后撤反击、**236D** 消耗 40 能量发射脉冲。数字方向用小键盘记法，6 为前，4 为后。连招支持组合按键、等待帧、编辑间隔。连招和手动输入使用相同的出招、距离及受击规则。打开「连招 / 按键设置」修改并保存。

## 本地运行

使用 Node.js 22 或更新版本。

~~~sh
npm run dev
npm test
~~~

打开终端显示的地址。游戏由浏览器原生模块运行，无运行时依赖。GitHub Pages 从 main 根目录提供静态文件。

## 代码和素材

键位与连招解析沿用作者自己的浏览器格斗项目。棱锚、流梭、码头和战斗特效由 Canvas 代码绘制。声效由 Web Audio 合成，战斗由仓库内的定步长引擎运行。
