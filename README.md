# 三国小将·虎牢争锋

Veldon 第 001 款自制网页格斗游戏。关羽横刀，吕布挺戟，百位 Q 版三国人物在虎牢关前交锋。支持单人挑战电脑、双人同屏和触屏操作。[网页试玩](https://rogerh2018.github.io/veldon-001-original-arc-harbor/)

## 点将与演武

蜀、魏各 30 人，吴、群雄各 20 人。点开任一方的名字，在点将台按势力筛选，或输入姓名、拼音、兵器搜索。点击招式名可以预演完整动作。每位人物有三套专属连招，近身快击、突进追击和耗气终结各一套。首击命中后才会接续。

## 默认操作

| 操作 | 1P | 2P |
| --- | --- | --- |
| 上、左、下、右 | W、A、S、D | 方向键 |
| A 快击、B 突进、C 重破、D 上挑 | J、K、U、I | 1、2、4、5 |
| 三套专属连招 | L、O、P | 3、6、9 |

后退或下蹲可以防御，普通重破可以破防。数字方向按小键盘排列，6 表示朝前。输入 **236A** 突阵、**214B** 回身反击，**236D** 消耗 40 能量发出劲风。按 **Esc** 暂停。单局 55 秒，先赢两局取胜。「连招 / 按键设置」可以改键或录入自定义宏。

## 招式克制

| 交锋 | 获胜的招式 |
| --- | --- |
| 快击对重破 | 快击截破 |
| 重破对突进 | 重破拦突 |
| 突进对快击 | 突进抢快 |
| 上挑对跃入的对手 | 对空迎击 |

打中尚在起手的劣势招式会造成额外 25% 伤害，增加 5 帧硬直。进入己方击点前 5 帧时，距离、朝向和高度合适的优势招式也能截住来招。相同类别在同一帧命中可以互换伤害。连招首段参与克制，后续各段按招式本身结算。

## 本地运行

使用 Node.js 22 或更新版本，在项目目录运行以下命令。

~~~sh
npm run dev
npm test
~~~

浏览器直接加载静态模块。包清单有零个第三方依赖。战鼓、铜锣、拨弦和箫声由 Web Audio 合成。

## 制作

人物动作谱按角色分别编排，手腕、兵器、躯干与步法在每个击点同步。头像、衣甲、主要兵器和虎牢关背景使用内置 ImageGen 绘制。素材随游戏本地加载。[美术提示词](assets/roster/PROMPTS.md) · [Veldon Game](https://github.com/RogerH2018/Veldon-Game)
