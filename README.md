# 三国小将·虎牢争锋

Veldon 第 001 款自制网页格斗游戏。关羽横刀，吕布挺戟，百位 Q 版三国人物在虎牢关前交锋。支持单人挑战电脑、双人同屏和触屏操作。[网页试玩](https://rogerh2018.github.io/veldon-001-original-hulao-showdown/?lang=zh)

初次进入时游戏会读取浏览器语言偏好。点右上角的 **English / 简体中文** 可随时切换，浏览器会记住选择。点将台、招式名称、触屏按键、克制提示与连招编辑器都支持两种语言。

## 点将与演武

蜀、魏各 30 人，吴、群雄各 20 人。点开任一方的名字，在点将台按势力筛选，或输入姓名、拼音、兵器搜索。点选四种基础招式或三套专属连招，都能看到该武将的完整演示。每位人物有三套专属连招，近身快击、突进追击和耗气终结各一套。首击命中后才会接续。

## 默认操作

| 操作 | 1P | 2P |
| --- | --- | --- |
| 上、左、下、右 | W、A、S、D | 方向键 |
| 快击、突进、重破、上挑 | J、K、U、I | 1、2、4、5 |
| 三套专属连招 | L、O、P | 3、6、9 |

关羽的「抚髯挑月」按 **左 → 快击 → 下 → 快击**。使用 1P 默认键位就是 **A → J → S → J**。每步按下后松开，左右始终以屏幕为准，两方的招式表都写有完整输入。点「连招 / 按键设置」，把一个快捷槽换成「自定义」，依次点上、下、左、右、快击、重破、突进或上挑，即可保存自己的组合。普通攻击会等前一招收势，完整输入一套专属指令可以衔接当前基础招式。

后退或下蹲可以防御，普通重破可以破防。按 **Esc** 暂停。单局 55 秒，先赢两局取胜。

旧设置里的 `A W8 236A` 仍可播放。`A` 指快击，`W8` 指在原有段间隔后额外等 8 帧，`236A` 指依次输入下、下前、前，最后一步同时快击。「前」随朝向变化。游戏每秒 60 帧，旧设置的默认段间隔是 16 帧。

## 招式克制

| 交锋 | 获胜的招式 |
| --- | --- |
| 快击对重破 | 快击截破 |
| 重破对突进 | 重破拦突 |
| 突进对快击 | 突进抢快 |
| 上挑对跃入的对手 | 对空迎击 |

打中尚在起手的劣势招式会造成额外 25% 伤害，增加 5 帧硬直。进入己方击点前 5 帧时，距离、朝向和高度合适的优势招式也能截住来招。相同类别在同一帧命中可以互换伤害。连招首段参与克制，后续各段按招式本身结算。

## 本地运行

使用 Node.js 22 或更新版本，在项目目录运行以下命令。

~~~sh
npm run dev
npm test
~~~

启动后在浏览器打开终端显示的本地地址，默认是 `http://127.0.0.1:4173/`。浏览器直接加载静态模块。包清单有零个第三方依赖。战鼓、铜锣、拨弦和箫声由 Web Audio 合成。

## 制作

100 位武将各有独立衣甲、四个具名基础招式及三套专属连招。双手、肩肘、膝踝和两脚随各自的动作谱分开运动。兵刃轨迹跟随握点，弓弦、双剑与琴弦各有自己的双手姿势。手腕从袖口自然伸出，短靴在踏步和落地时由脚跟向前掌过渡。头像、身体部件、主要兵器与虎牢关背景使用 ImageGen 绘制，随游戏本地加载。品牌图标取自 Veldon Game 主项目。[头像、兵器与背景](assets/roster/PROMPTS.md) · [衣甲与四肢](assets/rig/PROMPTS.md) · [Veldon Game](https://github.com/RogerH2018/Veldon-Game)
